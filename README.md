# 风电施工现场管理 · uni-app

微信小程序、Android、iOS 统一维护这一份 Vue 3 + TypeScript 源代码。原 Capacitor APP 和手写微信界面已由本工程替换，原项目大屏、工程后台与上传资料不变。

## 快速查看

在 VS Code 打开 `E:\Work\Wind-Demo\mobile`，首次执行 `npm ci`，然后：

| 任务            | 命令                      | 说明                                                                    |
| --------------- | ------------------------- | ----------------------------------------------------------------------- |
| 电脑预览        | `npm run dev`             | 真正的 uni-app H5，http://127.0.0.1:5188                                |
| 同一 Wi-Fi 联调 | `npm run dev:lan`         | 显示电脑局域网地址；仅开发测试                                          |
| 编译微信        | `npm run build:mp-weixin` | 生成到原 `../miniprogram/client`，在微信开发者工具导入 `../miniprogram` |
| 微信监听编译    | `npm run dev:mp-weixin`   | 保持编译，修改源文件后更新                                              |
| 编译安装版资源  | `npm run build:app`       | 输出 `dist/build/app`，不是 APK 或 IPA                                  |
| 类型校验        | `npm run typecheck`       | Vue 与 TypeScript                                                       |
| 业务与服务测试  | `npm test`                | 测试使用独立临时目录，不写正式大屏                                      |

默认移动端业务服务在 127.0.0.1:8790；统一照片适配入口在 8791。开发预览自动代理到 8791。它们与原大屏 5173/8787 分开，不会自动终止占用端口的其他程序。

`dev` 用于修改代码和热更新，首次跳转页面可能需要开发服务器编译，不能代表离线安装版。要在浏览器验证断网重载，请先停止 `dev`，改用 `npm run preview`（自动先编译生产资源）；两种预览使用同一端口，不要同时启动。同一 Wi-Fi 下可用 `npm run preview:lan`，正式 APP 和小程序则使用各自的打包资源。

## 文件组织

```text
mobile/
  src/
    pages/                  登录、工作台、记录、填报、详情、我的、设置
    components/             通用页头、图标、照片预览
    modules/
      work/                 施工业务：模型、台账、接口、上传队列、页面状态
      platform/             平台适配：持久化存储、相机与照片
    styles/                 全端统一视觉基础
    static/                 本地图标与背景，无外部字体/图标请求
    pages.json              页面与底部导航
    manifest.json           微信/Android/iOS 配置
  server/                   保留的账号、原系统归档接口及统一上传适配层
  scripts/                  启动、编译与静态资源生成
  tests/                    业务、接口、大屏联动和 H5 操作测试
  .local-data/private/      原账号与试用台账（不提交、不覆盖）
miniprogram/
  client/                   uni-app 自动生成，不在这里手工修改业务代码
  project.config.json       微信开发者工具入口
```

大屏代码只在原工程维护，移动端页面只在 `mobile/src` 维护；不再双份修改 APP 与小程序。

## 已实现的工作流

### 登录身份与项目工作台账

- 登录页的用户名和密码均为空；没有账号点击“先注册”。注册填写用户名、密码并选择工作人员或管理人员；管理人员额外填写姓名，工作人员不要求姓名。用户名由服务端唯一校验，已有账号仍可登录。
- 工作人员：快速填报七类施工记录，拍照/选图，管理自己的草稿、待上传任务和已提交记录；不提供项目级台账和图表入口。
- 管理人员：保留全部个人填报能力，首页显示项目工作台账及真实统计，可查看各人员通过本移动端提交的记录、施工说明与现场照片。
- 管理图表：近7/30/90天及全部施工日期筛选，记录/照片趋势切换、七类施工类型分布、审核环形图、每条记录的照片数量分布；不展示姓名或姓名排行。90日趋势按连续七日汇总；选择全部时，趋势图明确展示近30日，其他指标按全部口径统计。
- 台账按提交时间倒序，支持施工类型、施工日期和地点/内容搜索。管理人员可查看所有移动端账号上传的详细记录和原图；工作人员个人接口只返回自己的记录。项目级查看为只读，原数据修改和审核仍由现有管理平台处理。
- 统计仅包含服务器确认归档的记录，不含个人草稿/未完成上传，不把资料条数、照片张数或审核通过率当作工程完成进度，也不以填报数量评价施工质量。
- 已连接原大屏且能读取其同主机台账时，审核和删除会同步反映；仅能读上传回执时明确显示回执统计，不能冒充原系统全部来源的实时台账。本功能统计此移动端提交的资料，不自动扩展为对原系统其他来源资料的读取授权。
- 项目级台账只在管理人员有效登录后读取，不写入个人离线队列；退出/切换账号时清除项目台账内存。离线时仍可填报自己的工作记录，项目汇总需联网获取。
- 两类身份均可按项目要求自助注册；管理人员也可在“我的 → 项目服务与账号”代开账号。项目台账和项目照片接口始终由服务端管理角色校验，工作人员直接调用也会被拒绝。**允许自行注册管理人员意味着任何能够进入注册入口的人都可申请管理权限；此规则按当前需求实现，正式公网部署前应增加管理员邀请或审批。**

新增代码集中在 `src/modules/work/ledger.ts`（统计口径）、`src/components/ManagementOverview.vue`（管理工作台）、`src/components/LedgerChart.vue`（跨端 Canvas 图表）和 `src/pages/ledger/index.vue`（工作台账）。原施工存储及补传逻辑继续共用。

1. 联网注册项目账号，选择工作人员或管理人员；管理人员填写姓名。用户名、密码初始为空，不保存密码。服务器使用 scrypt 加盐派生、短期会话和登录/注册限流。
2. 七类施工记录：风机基础、道路、吊装、集电线路、升压站、风机运输、其他。日期、地点、说明、1—10 张 JPG/PNG/WEBP 原始照片，单张 20 MB；原图不做隐式压缩。
3. 表单更改自动保存为草稿，也可明确保存。拍照/选图后先持久化照片，成功后才显示在本机记录中；临时路径不会被当成可靠存储。
4. 点击提交：先保存本机任务，在线并有有效登录时立即上传；断网时排队。只有服务器完整接收照片和日志并返回归档回执，才标记“已提交”。
5. 照片、记录均有固定 UUID。照片回执逐张保存；超时或中断重试使用同一编号。断点续传是**已完成照片不重复上传，未完成单张重新上传**，不是文件字节级续传。
6. 网络恢复、应用回前台、前台定时检查和手动重试会继续待办。普通草稿不会自动提交。业务错误停止自动重试，网络错误退避重试。
7. 提交记录、审核状态和后台删除可同步到个人台账。账号/服务器实例/项目通道隔离，切换服务不删除旧资料，也不自动转发旧任务。

## 离线边界与资料保护

- Android/iOS：SQLite 事务存储元数据；照片存放应用持久目录。
- 微信：私有文件 A/B 完整性快照，照片独立保存，不把大图/base64 放进小容量键值存储。
- H5：IndexedDB 保存元数据和照片，沿用旧浏览器数据库，避免直接清空旧记录。生产构建的应用资源支持离线缓存，首次成功加载缓存后可断网重载；不缓存登录接口、API 响应或服务器照片。
- 首次使用必须联网验证。验证后可在 7 天本机使用期限内点击“继续本机离线填报”；这不是服务器登录，不授予离线服务器访问。联网重新登录后才能上传。退出账号会移除离线入口，资料仍留存。
- 登录令牌仅在内存中；应用重启/会话失效后需联网登录上传，不落盘密码或长期通用 API 密钥。
- **离线入口意味着信任当前手机解锁者；共用手机请主动退出，不要将它视为生物识别或强离线认证。**
- 后台、锁屏和系统杀进程时不保证持续上传；任务在再次进入应用后恢复。小程序/H5 离线能力限于客户端仍能打开或原生已缓存的页面，不承诺断网首次启动。
- 卸载、清除微信/浏览器数据会删除未上传资料；已上传资料保存在服务器，不会跟随手机清理删除。
- 旧微信快照、旧 H5 台账兼容读取；同签名同包名升级 APP 会尝试只读导入旧 Capacitor 私有目录。**原生迁移必须真机核对，未核对前不要卸载旧版或清除数据。**

## 接入原大屏

正式启动默认自动连接同机数字化管理平台，不再要求粘贴每天到期的填报链接。

1. 在 `E:\Work\Wind-Demo` 启动或重启 `npm run dev`，使电脑端资料服务启用内部同步通道。
2. 在 `E:\Work\Wind-Demo\mobile` 启动或重启 `npm run dev`（同 Wi-Fi 手机测试用 `npm run dev:lan`）。
3. APP、小程序和 H5 都连接这同一移动端服务。后台经本机私有通道把照片、日志交给原施工服务，按原有规则命名归档；大屏和电脑数据管理约每5秒读取同一份台账，不需另存或手工复制。
4. 电脑端服务断开时不会退回试用台账，也不会将记录标为提交成功；已保存任务在服务和登录恢复后续传。电脑端对记录的审核、修订与删除，会在移动端同步时回读。

默认施工资料根目录仍为 `E:\Work\Wind-data`；如已修改根目录或端口，两服务须使用一致的 `WIND_DATA_ROOT`、`WIND_API_PORT`。内部密钥在该资料根目录的 `private/mobile-sync.json`，不向 APP、小程序或普通上传网关公开，也不授予电脑后台管理权限。服务端保持单实例写台账。旧试用记录及原账号保留，不自动把旧测试数据发布至正式项目。

需要隔离演示/自动化测试时，可设置 `WIND_MOBILE_TRIAL=1`，该模式明确不写入正式项目。仅在此测试模式下保留原有手动链接连接能力。

## 微信与安装包发布前还需准备

- 微信小程序：在 `src/manifest.json` 填实际 AppID（外层 project.config.json 保持一致），配置合法 HTTPS request/uploadFile/downloadFile 域名、隐私保护指引与所需照片接口声明。游客 AppID 仅能体验有限调试能力，不能正式发布。
- Android：DCloud AppID、应用签名/证书、HBuilderX 对 CLI 编译资源打包。继续使用包名 `com.windproject.fieldmanagement`；覆盖已装版本还必须使用同一签名。
- iOS：DCloud AppID、Apple 开发者账号、Bundle ID 对应证书与描述文件；通过 HBuilderX 云打包或 macOS/Xcode 打包。真机分发按 Apple 流程（如 TestFlight），不能在 Windows 直接生成任意可安装 IPA。
- 后续服务器：将移动端服务与施工后台部署到可信主机，8790 保持内网，8791 通过 HTTPS 反向代理发布。不要直接把开发端口暴露公网。配置 `WIND_MOBILE_ORIGINS` 精确允许 H5 来源，不使用通配跨域。
- 发布前完成两类真实手机验证：拒绝相机权限、无网络拍照、杀进程重启、逐张补传、低空间、账号切换、旧版升级迁移；H5 自动化和资源编译不能替代它们。
